# Мой планировщик

Личный Telegram-бот на Python. В 05:00 по Москве он присылает описание дня, аффирмацию и задачи, а в 21:00 предлагает закрыть задачи, оценить день, записать заметку и благодарности. Открытые задачи остаются в списке на следующий день. Утром бот один раз предлагает заполнить пропущенный итог, если вечером напоминание было поставлено в очередь. В первый день месяца присылает Markdown-отчёт за предыдущий месяц с оценками, дневником, благодарностями и днями с самой высокой и низкой оценкой.

В этой версии ввод текстовый. Два иероглифа Ба-цзы и описание можно задать заранее на любую дату, по одной команде на дату. Автоматический расчёт Ба-цзы, распознавание голосовых и график оценок пока отсутствуют.

## Развёртывание

1. В Telegram открой [@BotFather](https://t.me/BotFather) и отправь `/newbot`. Введи имя **Мой планировщик** и придумай уникальное имя пользователя с окончанием `bot`. Полученный токен понадобится только в настройках Render.
2. Создай проект на [Neon Free](https://neon.com/). В окне **Connect** скопируй строку подключения к PostgreSQL. Подойдёт прямая строка подключения с параметром `sslmode=require`. Параметр `DATABASE_URL` хранится только в Render.
3. Файлы проекта уже находятся в корне GitHub-репозитория `my-planner-bot`. Не добавляй токен, строку подключения или секреты в GitHub.
4. В [Render Dashboard](https://dashboard.render.com/) выбери **New → Blueprint**, подключи GitHub и выбери этот репозиторий. Render прочтёт `render.yaml`. Проверь, что создаётся один **Web Service** с тарифом **Free**. Введи `BOT_TOKEN`, `DATABASE_URL` и `OWNER_ID`. Если ты не знаешь свой Telegram ID, укажи `0` для первого запуска. Render сгенерирует два секрета.
5. Дождись статуса **Live**. Если указала `OWNER_ID=0`, отправь своему боту `/id` в личном чате. Скопируй число в **Render → сервис → Environment → OWNER_ID** и примени изменение с перезапуском. В режиме `0` доступны только ответы на `/id`. Затем отправь `/start` и добавь пробную задачу.
6. В [cron-job.org](https://cron-job.org/) создай бесплатное расписание. Укажи URL из Render с окончанием `/tick`, метод **POST**, минуты **0, 12, 24, 36, 48** каждого часа и заголовок **Authorization** со значением `Bearer ` плюс значение `CRON_SECRET` из Render. Используй ровно один пробел после `Bearer`. Для проверки сначала открой в браузере URL сервиса с окончанием `/health`, дождись ответа `200 OK`, затем запусти тестовый вызов в cron-job.org.
7. Отправь боту `/remind 1м Проверка`. Проверь, что напоминание пришло после следующего запуска расписания.

### Если Blueprint не показывает нужный репозиторий

Проверь в GitHub, что приложению Render разрешён доступ к `my-planner-bot`. Можно также создать сервис через **New → Web Service**, выбрав Python и Free. Команда сборки `pip install -r requirements.txt`. Команда запуска указана в `render.yaml` в поле `startCommand`. Укажи путь проверки `/health` и добавь пять переменных окружения. Для `WEBHOOK_SECRET` и `CRON_SECRET` используй разные случайные значения не короче 32 символов.

### Как работает расписание

Обычная задержка разового напоминания — до 12 минут плюс время запуска сервиса, если он уснул. Если вызов пропущен, следующий успешный запуск отправит просроченные разовые напоминания. Утреннее сообщение может догонять до 21:00, вечернее до полуночи. Render Free может прерывать работу из-за лимитов или перезапусков. Данные остаются в Neon при перезапусках Render. Для расписания нужна активная задача cron-job.org и рабочая база Neon. Telegram может получить повтор сообщения, если соединение оборвётся после приёма сообщения и до фиксации отправки в базе.

## Команды

| Команда | Что делает |
| --- | --- |
| `/start` | Показать меню и подсказки |
| `/add Купить фурнитуру` | Добавить задачу |
| `/today` | Показать задачи и описание дня |
| `/day 2026-12-01 甲子 День грабителя` | Задать иероглифы и описание на дату |
| `/affirm Сегодня я действую спокойно` | Изменить утреннюю аффирмацию |
| `/remind 1ч Позвонить` | Напомнить через час |
| `/remind 3д Позвонить` | Напомнить через три дня |
| `/remind 1мес Позвонить` | Напомнить через календарный месяц |
| `/remind 2026-12-01 18:30 Позвонить` | Напомнить в указанное время по Москве |
| `/reminders` | Посмотреть или отменить напоминания |
| `/evening` | Заполнить вечерний итог |
| `/report 2026-12` | Скачать отчёт за указанный месяц |
| `/cancel` | Отменить текущий ввод записи |
