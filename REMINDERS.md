# Напоминания обычными словами

Тестовая ветка feature/natural-reminders основана на рабочем коммите
1d2da8c2c0e7ac55d941f0cae1bd7c3611cc6fae. Для выпуска потребуется отдельное
разрешение владельца. Render и cron-job.org используют прежнюю конфигурацию.

Можно отправить:
- Напомни мне сегодня в 15:00 выпить чай
- Напомни завтра в 10:00 позвонить врачу
- Напомни через 30 минут сделать перерыв
- Напомни через 3 дня проверить заказ
- Напомни 2026-12-01 в 10:00 проверить заказ
- Напомни 01.12.2026 в 10:00 проверить заказ

Бот показывает дату и время по Москве и предлагает «Подтвердить», «Исправить»,
«Отменить». До подтверждения напоминание хранится только как черновик.
При исправлении нужно ввести всю фразу с датой, временем и текстом.
Старые кнопки подтверждения больше не действуют. Если время уже прошло,
бот попросит новое время. При неоднозначном вводе бот попросит уточнение.

«Через 3 дня» означает через три календарных дня в тот же час и минуту
по Москве. Для другого времени используйте явную дату с часами.
Даты определяются по времени получения сообщения ботом.

Команда /remind сохраняет прежнее поведение, включая немедленное создание.
Команда /cancel отменяет текущий ввод и черновик, сохраняя готовые напоминания.

При переходе к напоминаниям незавершённый дневник приостанавливается.
Кнопка «Продолжить итог за …» возвращает к ожидаемому этапу, сохранив
предыдущие записи. Ввод за прошлую дату требует явного продолжения.
Если после продолжения прошло ещё одно московское число, бот снова
попросит продолжить явно. Обычный текст не дописывается молча за прошлый день.

Существующее расписание проверяет очередь примерно раз в 10 минут.
Напоминание отправляется при первой успешной проверке после наступления
его времени. Повторное подтверждение того же черновика не создаёт копию,
включая два одновременных Telegram callback в PostgreSQL.
Доставка проверяется с подменой Telegram API в тестах. Реальные сообщения
в рабочий Telegram тесты не отправляют.

Технически черновик и приостановленный этап хранятся в дополнительных ключах
существующего JSON data. Новые колонки и миграции не нужны.
При откате старый код игнорирует дополнительные ключи, готовые напоминания
имеют прежний формат due/text.

Автотесты запускаются командой python -m unittest discover -s tests -v.
GitHub Actions запускает отдельную PostgreSQL 16. Подтверждения, очередь,
доставка, дневник, задачи и чтение профиля проверяются без рабочей базы.
